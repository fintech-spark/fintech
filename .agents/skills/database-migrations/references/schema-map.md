# Schema map

27 tables (26 domain + `_migrations`). Defined in `20261002000001_core_tables.sql`, extended by
`0005` (storage), `0010` (chunk provenance), `0011` (intelligence detail columns).
TypeScript mirror: `database/schema.ts` (`DATABASE_TABLES`), `database/rows.ts` (row shapes).

| Group | Tables | Tenant column |
|---|---|---|
| Tenant root | `businesses` | — (is the tenant) |
| Identity | `users` | — (mirrors `auth.users.id`) |
| Membership | `business_members` | `business_id` + `user_id`, unique `(business_id, user_id)` |
| Financial | `transactions`, `transaction_items`, `expenses`, `receivables`, `payables` | `business_id` (`transaction_items` via parent) |
| Merchant ops | `products`, `inventory_movements`, `supplier_pricing`, `customers`, `suppliers` | `business_id` |

| Execution | `actions`, `action_logs`, `chat_sessions`, `chat_messages`, `notifications`, `audit_logs` | `business_id` (`action_logs` added `0011:98`; `chat_messages` via parent) |

## Conventions

- PKs are `uuid`, generated by `extensions.gen_random_uuid()` via `public.gen_uuid()`.
- `business_id uuid NOT NULL REFERENCES businesses(id) ON DELETE RESTRICT` — RESTRICT prevents
  silently deleting a tenant with data. `document_embeddings` cascades.
- Money: `bigint` minor units with a `CHECK`. Never float, never `numeric`.
- Timestamps: `timestamptz NOT NULL DEFAULT now()`; `updated_at` maintained by 14 triggers.
- Idempotency: partial unique indexes on `transactions`, `expenses`, `actions`; plus
  `idx_documents_content_hash` and `idx_products_low_stock`.
- Vector: `document_embeddings.embedding vector(1536)`, nullable; HNSW `vector_cosine_ops`
  (`0002:117`, **not** partial).

## Drift to be aware of

`database/rows.ts` is behind the SQL: `ActionLogRow` still declares `status` (dropped by `0011:157`)
and omits `business_id, from_status, to_status, outcome, actor_id, actor_role, actor_is_machine,
reason, parameters_hash, executor_id, idempotency_key, correlation_id`. `DocumentEmbeddingRow` omits
`chunk_index, total_chunks, chunker_version, embedding_model, content_hash` (`0010:35-40`).
`ProfitLeakRow`/`ScenarioRow` omit `detail`; `ActionRow` omits `currency` and `detail`.

`tests/database-schema.test.ts` is a **static** test — it concatenates the migration SQL and greps.
It cannot detect runtime divergence, and its table-count assertion is `>= 27`, so extra tables slip
through. `tests/database-security.test.ts` is the live counterpart and requires `LOCAL_DATABASE_URL`.
